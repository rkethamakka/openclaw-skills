# Writing Script Skill

Write screenplays through a guided, linear workflow. One step at a time, confirm before proceeding.

## Trigger

Use when user wants to write a script, screenplay, short film, or scene.

## Workflow

Follow these steps IN ORDER. Do not skip. Confirm each step before moving on.

### Step 1: Constraints

Ask for:
- **Duration**: How many minutes of screen time?
- **Language**: What language for dialogue?
- **Genre/tone** (optional): Can decide later from ideas

**Calculate scene count** based on duration:
- Rule of thumb: 1.5-2 min per scene
- 5 min → 3 scenes
- 10 min → 5-6 scenes
- 15 min → 7-10 scenes
- 30 min → 15-20 scenes

Present the suggested scene count. User can adjust if needed.

If user doesn't specify, suggest defaults:
- 10 minutes, English

### Step 2: Idea Generation

Generate **3-5 story ideas** that fit the constraints.

Each idea should include:
- **Logline**: One sentence premise
- **Genre/tone**: Comedy, drama, thriller, etc.
- **Core conflict**: What's the tension?
- **Why it fits**: How it works in X scenes / Y minutes

Present ideas numbered. Ask user to pick one (or request more ideas).

### Step 3: Idea Deep-Dive & Confirmation

Once user picks, DO NOT lock in immediately. Run multiple question loops:

**Loop A: Story Angles**
- Restate the chosen idea
- Tone refinement: How dark/light? Realistic or stylized?
- Genre blend: Pure genre or hybrid (sci-fi + horror, comedy + drama)?
- Ending type:
  - **Resolved**: Story concludes, questions answered
  - **Twist**: Revelation changes everything
  - **Open/Ambiguous**: Audience interprets
  - **Cliffhanger/Pilot**: No ending, hooks for more, "wait for next episode" feeling
- Themes to emphasize?

**Loop B: Production Reality**
- **Scale**: Intimate (1-2 locations) vs ambitious (multiple locations)?
- **VFX requirements**: None, minimal (phone screens), moderate, heavy?
- **Cast size**: How many speaking roles? Extras needed?
- **Locations**: Accessible? Need permits? Night shoots?
- **Props/vehicles**: Anything expensive or hard to source?
- **Budget tier**: No-budget, low, medium, high?

**Loop C: Practical Constraints**
- Any locations you already have access to?
- Any actors/crew already attached?
- Timeline to shoot?
- Any equipment limitations?

**Loop D: Creative Preferences**
- Reference films for tone/style?
- Dialogue style: Realistic, stylized, minimal?
- Pacing: Slow burn vs fast cuts?
- Music/sound design vision?

Ask these in batches. User can skip loops if not relevant.
Only after these loops, summarize and ask to lock in.

### Step 4: Characters

Based on the idea, propose:
- **Main character(s)**: Name, brief description, goal
- **Supporting characters**: Who else is needed
- **Antagonist/obstacle**: What's in the way

Keep it minimal. Only characters needed for the story.

Ask user to confirm or modify.

### Step 5: Scene Outline

Create a scene-by-scene breakdown:

```
SCENE 1 - [Location] - [Approx duration]
Brief description of what happens. Goal of the scene.

SCENE 2 - [Location] - [Approx duration]
...
```

Total should match the target duration.

Ask user to confirm the outline before writing.

### Step 6: Write Scenes (Loop)

For each scene:
1. Write the scene in screenplay format
2. Present to user
3. Get feedback (good / revise / notes)
4. If revise, update and re-present
5. Once approved, move to next scene

**Do not write multiple scenes at once.** One at a time.

### Step 7: Full Script Review

After all scenes written, BEFORE final assembly:

**Review Pass 1: Consistency Check**
- Character voice consistent throughout?
- Tone maintained or intentionally shifted?
- Timeline/continuity errors?
- Any plot holes?

**Review Pass 2: Production Review**
- Does it still fit the agreed scale/budget?
- Any scene creep (became bigger than planned)?
- VFX/practical effects still manageable?
- Location count still realistic?

**Review Pass 3: Screenplay Format**
- Formatting consistent?
- Scene headings correct?
- Action lines tight (not prose-y)?
- Dialogue formatted properly?
- Page count matches target duration? (~1 page = 1 minute)

Present findings. Allow adjustments to ANY scene based on review.

### Step 8: Assembly

After review approved:
- Compile full script
- Add title page (Title, Writer, Draft date, Contact)
- Present complete screenplay

Ask if user wants any final changes.

### Step 9: Export

Offer to save as:
- Markdown file
- Fountain format (.fountain)
- PDF (if tooling available)

## Screenplay Format

Use standard screenplay format:

```
INT. LOCATION - TIME

Description of action and setting.

CHARACTER NAME
Dialogue goes here.

CHARACTER NAME (CONT'D)
More dialogue if same character continues.

(beat)

CHARACTER NAME
After a pause.
```

**Conventions:**
- INT. = Interior, EXT. = Exterior
- CAPS for character names on first appearance
- CAPS for important sounds or objects
- Parentheticals for delivery notes: (whispered), (angry)
- Transitions: CUT TO:, FADE OUT., etc. (use sparingly)

If user returns mid-process, resume from last confirmed step.

---

## Rules

1. **Linear only**: Don't jump ahead
2. **Confirm before proceeding**: Always get explicit OK
3. **One scene at a time**: No bulk writing
4. **Revisions welcome**: Any step can be revised before moving on
5. **Stay in character**: Maintain tone consistency throughout
6. **Duration math**: Keep scenes within target screen time
